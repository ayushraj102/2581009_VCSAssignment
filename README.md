# CampusNotes

CampusNotes is a simple project designed to help students organize and manage their academic notes.

## Project Overview

The project demonstrates how Git and GitHub can be used to manage project files, track changes, and collaborate with other developers.

## Objectives

- Organize academic notes.
- Maintain project documentation.
- Practise Git version control.
- Understand GitHub collaboration.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/ayushraj102/2581009_VCSAssignment.git
```

### Navigate to the Project

```bash
cd 2581009_VCSAssignment
```

### Check Repository Status

```bash
git status
```

## Git Collaboration Workflow

1. Fork the original repository.
2. Clone your fork.
3. Add the original repository as upstream.
4. Create a feature branch.
5. Make and commit changes.
6. Push the feature branch.
7. Open a Pull Request.

## Contribution Guidelines

- Create a separate branch for each feature.
- Use meaningful commit messages.
- Keep documentation updated.
- Review changes before merging.

## Version Control

This repository is maintained using Git and GitHub.
